Forex • Crypto • Gold • Indices

---

## 🚀 Overview

Merced’s Trading Bot is an intelligent trading system designed to:

- Analyze market data in real-time
- Generate BUY / SELL / HOLD signals
- Apply technical indicators (RSI, Stochastic, Standard Deviation)
- Manage risk automatically based on user capital
- Support multi-timeframe analysis
- Track trade performance (TP / SL)

> ⚠️ This project is for educational and simulation purposes. It does not guarantee profits.

---

## 🧠 Core Features

### 📊 Signal Engine
- BUY / SELL / NONE decision system
- Confidence scoring (0–100)
- Entry price calculation
- Stop Loss & Take Profit (TP1 / TP2 / TP3)
- Reason-based explanations (RSI, momentum, breakout)

---

### 📈 Technical Indicators

  - H1
  - H4
  - D1
